Ollama Backup Deluxe

Fully offline-restorable backups of your local inference stack

⚡ Connected to your local engine at — full functionality below.
Static copy — the backup/restore engine runs on your Mac

For security, no web page can read your disk or run scripts — the backup engine is a small local app. Setup takes about a minute:

  1. ⬇ Download the latest release Grab the latest ollama-backup-deluxe-vX-macos.zip from this project's GitHub Releases.
  2. Unzip it, then in Terminal: 
    cd ollama-backup-deluxe-v*-macos
./start-webapp.sh
  3. The local app opens at http://127.0.0.1:8686 — this page will connect to it automatically within a few seconds.

Optional — let this hosted page control your local engine (instead of using the local copy of the UI): quit the local app and restart it with 

OBD_ALLOWED_ORIGIN="" ./start-webapp.sh
then reload this page. Only set that origin to this site.
